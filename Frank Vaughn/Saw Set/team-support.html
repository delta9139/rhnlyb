Support for Saw Set

Saw Set is a free iOS app by Frank Vaughn. Email frank.vaughn35@163.com.

A tooth stays bent only when it goes the opposite way from the previous kept tooth, and only one step. The same way springs back. Two steps spring back past the plate. A tooth that is already kept is held. When all eight alternate, the saw is Set.

Saws stay on this iPhone. There is no account and nothing to buy. The app does not set the saw for you. Questions: frank.vaughn35@163.com.
